## 📝 Dev Notes

- Usar `cn()` utility (Shadcn pattern) para mergir classes Tailwind
- Dark mode: `className="dark"` no root html
- Responsive: mobile-first approach
- TypeScript: `interface` para props, `type` para aliases
- Componentes Shadcn via `npx shadcn-ui@latest add [component]`
- Font: Inter via next/font
- Prefira `<Link>` do Next.js em vez de `<a>`
