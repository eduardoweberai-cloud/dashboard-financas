# Story 2.2: KPIs (Cards Receitas | Despesas | Saldo)

**Status:** Ready
**Story ID:** 2.2
**Objective:** Exibir métricas principais com Realizado, Projetado e % de realização

---

## 📋 Descrição

Criar 3 cards lado a lado (Receitas, Despesas, Saldo) onde cada card exibe 3 linhas:
1. Valor realizado (R$) grande + badge com variação vs período anterior (↑ verde / ↓ vermelho)
2. Projetado: R$ em cinza/subtil
3. % de realização com cores: Verde (≥100%), Amarelo (80-99%), Vermelho (<80%)

Integrar com API `/api/dashboard` para buscar dados de Supabase.

**PRD Reference:** Seção "KPIs Principais (Cards)" (p. 57-77)
**Architecture Reference:** GET /api/dashboard, componentes KPISection
**Design Reference:** KPI Card design tokens (p. 298-348)
