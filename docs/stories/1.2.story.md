# Story 1.2: Sincronização Fase 0 (Orçamento2026 → Supabase)

**Status:** Ready
**Story ID:** 1.2
**Objective:** Importar metas projetadas de Orçamento2026 para Supabase uma única vez

---

## 📋 Descrição

Criar script que lê planilha Orçamento2026 via Google Sheets API, mapeia 9 categorias de entrada + 21 de saída, normaliza nomes (lowercase), valida dados e insere em tabela `monthly_budgets` (12 meses × 30 categorias ≈ 360 linhas).

**PRD Reference:** Seção "Sincronização Inicial de Metas" (p. 241-249)
**Architecture Reference:** Fluxo 2 "Re-sincronização de Metas"

---

## ✅ Acceptance Criteria

- [ ] Script lê Orçamento2026 sem erros
- [ ] Mapeamento de 9 categorias entrada + 21 saída implementado
- [ ] Normalização de nomes (lowercase, sem acentos)
- [ ] 12 meses × 30 categorias = ~360 linhas inseridas em `monthly_budgets`
- [ ] Validação: valores > 0, ano válido, mês 1-12
- [ ] Teste: Executar script e validar dados em DB
- [ ] Re-sincronização possível: DELETE + INSERT (sem duplicatas)
- [ ] Log de sucesso registrado em `sync_log` table
- [ ] Erro handling: retry automático 1x se falhar
- [ ] Teste: Orçamento2026 alterado → script re-sincroniza corretamente

---

## 🎯 Scope

**IN:**
- Script que lê Orçamento2026
- Mapeamento de categorias (entrada + saída)
- Validação de dados
- Upsert em `monthly_budgets` (DELETE old + INSERT new)
- Log em `sync_log`
- Tratamento de erros básico

**OUT:**
- UI para botão resincronizar (Story 2.8)
- Toast/feedback (Story 2.8)
- Cron automático (é Story 1.3, não Story 1.2)
- Toggle Realizado/Projetado (Phase 2)
