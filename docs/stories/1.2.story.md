# Story 1.2: Sincronização Fase 0 (Orçamento2026 → Supabase)

**Status:** InReview
**Story ID:** 1.2
**Objective:** Importar metas projetadas de Orçamento2026 para Supabase uma única vez

---

## 📋 Descrição

Criar script que lê planilha Orçamento2026 via Google Sheets API, mapeia 9 categorias de entrada + 21 de saída, normaliza nomes (lowercase), valida dados e insere em tabela `monthly_budgets` (12 meses × 30 categorias ≈ 360 linhas).

**PRD Reference:** Seção "Sincronização Inicial de Metas" (p. 241-249)
**Architecture Reference:** Fluxo 2 "Re-sincronização de Metas"

---

## ✅ Acceptance Criteria

- [x] Script lê Orçamento2026 sem erros
- [x] Mapeamento de 9 categorias entrada + 21 saída implementado
- [x] Normalização de nomes (lowercase, sem acentos)
- [x] 12 meses × 30 categorias = ~360 linhas inseridas em `monthly_budgets`
- [x] Validação: valores > 0, ano válido, mês 1-12
- [x] Teste: Executar script e validar dados em DB
- [x] Re-sincronização possível: DELETE + INSERT (sem duplicatas)
- [x] Log de sucesso registrado em `sync_log` table
- [x] Erro handling: retry automático 1x se falhar
