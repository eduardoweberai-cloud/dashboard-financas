# Story 2.3: Seletor de Período (Mensal | Trimestral | Semestral | Anual)

**Status:** Ready
**Story ID:** 2.3
**Objective:** Implementar seletor dinâmico de período para filtrar dados do dashboard

---

## 📋 Descrição

Criar controle interativo com buttons [Mensal] [Trimestral] [Semestral] [Anual]. Ao selecionar tipo, dropdown dinâmico aparece com opções (12 meses, 4 trimestres, 2 semestres, anos). Clique atualiza React state e re-renderiza todos gráficos, KPIs e tabelas com dados do período selecionado.

**PRD Reference:** Seção "Seletor de Período" (p. 48-55)
**Architecture Reference:** PeriodContext, DashboardHeader component
**Design Reference:** Button design tokens

---

## ✅ Acceptance Criteria

- [ ] Buttons exibem 4 opções: Mensal, Trimestral, Semestral, Anual
- [ ] Clique em tipo mostra dropdown dinâmico
- [ ] Dropdown Mensal: 12 meses com labels em português (Janeiro, Fevereiro, etc)
- [ ] Dropdown Trimestral: Q1, Q2, Q3, Q4
- [ ] Dropdown Semestral: Semestre 1, Semestre 2
- [ ] Dropdown Anual: Anos disponíveis nos dados (2025, 2026, etc)
- [ ] Teste: Selecionar Janeiro → KPIs mostram dados de janeiro
- [ ] Teste: Selecionar Q1 → KPIs agregam jan+fev+mar
- [ ] Teste: Trocar período → gráficos atualizam em tempo real
- [ ] Estado persiste em React Context
- [ ] Visual feedback: tipo/período selecionado está destacado
- [ ] Responsivo: dropdown ajusta em mobile
- [ ] Acessibilidade: keyboard navigation (arrow keys)
- [ ] Default: Período atual (ex: janeiro 2026 se mês atual for janeiro)

---

## 🎯 Scope

**IN:**
- DashboardHeader component com buttons + dropdown
- PeriodContext para estado global
- Lógica de agregação por período (mensal, trimestral, etc)
- Validação de datas (só mostrar períodos com dados)
- Keyboard accessibility
- Visual feedback do período selecionado

**OUT:**
- Backend query otimizado (já em GET /api/dashboard)
- Comparação lado-a-lado de períodos (Phase 2)
- Filtros avançados (Phase 2)
