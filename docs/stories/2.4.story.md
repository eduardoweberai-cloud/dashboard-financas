# Story 2.4: Gráficos (Donuts Categorias + Barras Evolução)

**Status:** Ready
**Story ID:** 2.4
**Objective:** Visualizar distribuição de categorias e evolução de saldo com Recharts

---

## 📋 Descrição

Integrar Recharts para criar 3 gráficos:
1. **Donut Despesas**: Cada fatia = categoria, label "Alimentação: R$ 8.400 (35%)"
2. **Donut Receitas**: Mesmo layout
3. **Bar Chart Evolução**: Dias do mês (mensal) ou mês-a-mês (trimestral/semestral/anual), Y-axis em R$, cores verde (positivo)/vermelho (negativo)

Adaptar dados ao período selecionado (Story 2.3).

**PRD Reference:** Seção "Gráficos de Distribuição (Donuts)" + "Gráfico de Evolução" (p. 79-103)
**Architecture Reference:** DistributionCharts, BalanceChart components, Recharts
**Design Reference:** Donut + Bar Chart design tokens (p. 352-425)
