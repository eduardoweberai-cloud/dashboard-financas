# Story 2.9: Badge de Erro & Alertas de Sincronização

**Status:** Ready
**Story ID:** 2.9
**Objective:** Avisar usuário se dados estão desatualizados por falha de sincronização

---

## 📋 Descrição

Exibir badge "⚠️ Últimos dados: [data-hora]" no canto superior direito se última sincronização falhar por > 24h. Cores: Amarelo (24-48h desatualizado), Vermelho (> 48h). Clique na badge tenta resincronizar (dispara Story 2.8). Badge desaparece quando sincronização bem-sucedida.

**PRD Reference:** Seção "Erro Handling - Badge de Erro" (p. 258-263)
**Architecture Reference:** sync_log table, error handling em APIs
**Design Reference:** Badge component em Shadcn/ui

---

## ✅ Acceptance Criteria

- [ ] Badge exibido no canto superior direito
- [ ] Badge aparece APENAS se última sincronização > 24h e status = error
- [ ] Tooltip mostra data/hora exata última sincronização com sucesso
- [ ] Cor amarela: 24-48h desatualizado

## 📝 Dev Notes

- Query sync_log: SELECT * WHERE status='success' ORDER BY sync_date DESC LIMIT 1
- Time diff: new Date() - last_sync_date (em horas)
- Thresholds: 24h = 86400000ms, 48h = 172800000ms
- Cores: amarelo #FFD700, vermelho #FF4757
- Polling: useEffect com interval 5min (300000ms)
- Badge icon: AlertCircle ou AlertTriangle
- Tooltip: "⚠️ Sincronização desatualizada há {hours}h. Última atualização: {date}"
- Clique: disparar refetch de /api/sync/budgets
