# Story 2.9: Badge de Erro & Alertas de Sincronização

**Status:** Ready for Review
**Story ID:** 2.9
**Objective:** Avisar usuário se dados estão desatualizados por falha de sincronização

---

## 📋 Descrição

Exibir badge "⚠️ Últimos dados: [data-hora]" no canto superior direito se última sincronização falhar por > 24h. Cores: Amarelo (24-48h desatualizado), Vermelho (> 48h). Clique na badge tenta resincronizar (dispara Story 2.8). Badge desaparece quando sincronização bem-sucedida.

**PRD Reference:** Seção "Erro Handling - Badge de Erro" (p. 258-263)
**Architecture Reference:** sync_log table, error handling em APIs
**Design Reference:** Badge component em Shadcn/ui

## 📝 Dev Notes

**Implementação Concluída:**

### 1. **Database Functions** (`lib/db.ts`)
   - `syncService.getLastSuccessfulSync()` - Query: status='success', order by completed_at DESC
   - `syncService.getLastErrorSync()` - Query: status='error' (para referência futura)

### 2. **Utility Functions** (`lib/utils.ts`)
   - `calculateHoursSinceSync(dateString)` - Calcula horas desde ISO string
   - `getStatusColor(hours)` - Retorna null/yellow/red baseado em thresholds (24h/48h)

### 3. **Custom Hook** (`hooks/useSyncStatus.ts`)
   - Polling: setInterval a cada 5min (300000ms)
   - Retorna: lastSuccessfulSync, hoursSinceSyncSuccess, syncStatusColor, isOutdated, isLoading, error, refetch()
   - Busca inicial + polling automático

### 4. **Component** (`components/dashboard/SyncErrorBadge.tsx`)
   - Renderiza APENAS se isOutdated && syncStatusColor (> 24h)
   - Cores Tailwind: amarelo (yellow-100/200) e vermelho (red-100/200)
   - Ícones: AlertCircle + RotateCw (lucide-react)
   - Tooltip: "⚠️ Sincronização desatualizada há {X}h. Última: {date}"
   - Click: dispara syncBudgets() com timeout 30s
   - Toast notifications: success/error via addToast()
   - Responsive: usa flex/gap/text-xs para mobile

### 5. **Integration** (`components/dashboard/DashboardHeader.tsx`)
   - SyncErrorBadge posicionado no topo direito (acima do SyncButton)
   - Flex div com justify-end para alinhamento correto

### 6. **Tests** (`tests/sync-error-badge.test.tsx`)
   - calculateHoursSinceSync: testa 1h, 24h, 48h
   - getStatusColor: testa null, yellow (24-48), red (>48)
   - Manual test checklist com 7 seções
