# Story 1.1: Setup Supabase & Google Sheets API

**Status:** Ready
**Story ID:** 1.1
**Objective:** Configurar infraestrutura de dados para sincronização de Google Sheets com Supabase

---

## 📋 Descrição

Estabelecer a base de infraestrutura necessária para o dashboard. Criar projeto Supabase, configurar tabelas (transactions, monthly_budgets, metas, chat_messages, sync_log), autenticar Google Sheets API, validar conexões bidirecionais e documentar configuração de ambiente.

**PRD Reference:** Seção "Integração Técnica" (p. 211-275)
**Architecture Reference:** Layer 3 (Data Access) + Layer 4 (Integrations)
