# Story 2.7: Chat com IA (Claude API Plano Pro)

**Status:** Ready for Review
**Story ID:** 2.7
**Objective:** Implementar chat inteligente com contexto de dados financeiros

---

## 📋 Descrição

Criar widget de chat flutuante no canto inferior direito que abre modal/drawer ao clicar. Usuário pode fazer perguntas sobre dados financeiros. Backend envia contexto (período, KPIs, categorias) junto à mensagem para Claude API, que retorna análises contextuais. Histórico mantido em Supabase `chat_messages` table com campo `periodo_contexto`.

**PRD Reference:** Seção "Chat com IA (Anthropic Claude)" (p. 140-162)
**Architecture Reference:** ChatDrawer, POST /api/chat, lib/claude.ts
**Design Reference:** Chat Widget design tokens (p. 463-527)

## 📝 Dev Notes

- Claude modelo: `claude-3-5-sonnet` (ou superior)
- Contexto payload: `{ message, periodo, tipo_periodo, kpis, categorias }`
- Prompt template: "Usuário visualizando [período]. KPIs: ... Responda em português."
- Histórico: carregar últimas 10 mensagens na abertura
- Widget: posição fixed bottom-right, 44px × 44px
- Drawer: width 360px (max 100% em mobile), max-height 480px
- Input height: 44px, padding 8px
- Mensagens: palavra-quebra longa (word-wrap)
- Acessibilidade: ARIA labels no widget, chatbox role
