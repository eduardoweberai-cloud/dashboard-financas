# Story 2.10: Configuração de Metas (Settings Page)

**Status:** Ready for Review
**Story ID:** 2.10
**Objective:** Criar página de settings para usuário configurar suas metas de economia (% mensal e R$ anual)

---

## 📋 Descrição

Página `/dashboard/settings/goals` com formulário para:
1. **Meta Mensal %** - Percentual das receitas a economizar (0-100%)
2. **Meta Anual R$** - Valor anual de economia esperado

Usuário configura uma vez, valores salvos no Supabase tabela `metas`, e a Story 2.6 usa esses valores.

## 📝 Dev Notes

- Usar Shadcn Input + Button components
- Form validation com regex ou Zod (simples)
- Toast notification ao salvar (shadcn/ui)
- Loading spinner durante API call
- Fallback aos valores padrão se DB vazio
- Usar `metasService.insert()` ou `update()` do lib/db.ts
- Estrutura Supabase `metas` table:
  ```
  - id (uuid)
  - title (string) - "Meta Anual 2026"
  - target_amount (number)
  - type (enum) - 'annual' ou 'monthly'
  - month (string) - YYYY para annual, YYYY-MM para monthly
  - created_at, updated_at
  ```
- Salvar como tipo 'annual' com month='2026' (ou year corrente)
- Salvar como tipo 'monthly' com month='2026-02' (period corrente)
