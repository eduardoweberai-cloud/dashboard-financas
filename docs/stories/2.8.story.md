# Story 2.8: Botão Resincronizar Metas (Fase 0 - UI)

**Status:** Ready
**Story ID:** 2.8
**Objective:** Permitir re-sincronização manual de metas projetadas com UI feedback

---

## 📋 Descrição

Criar botão "↻ Resincronizar Metas" no canto superior direito do dashboard (próximo ao seletor de período). Clique dispara API `/api/sync/budgets` (implementado em Story 1.2). Exibe loading spinner enquanto sincroniza. Toast feedback ao completar: "Metas atualizadas com sucesso" (sucesso) ou "Erro ao sincronizar" (erro). KPIs e gráficos atualizam automaticamente após sucesso.

**PRD Reference:** Seção "Sincronização Inicial de Metas" (p. 241-249), UI (p. 247)
**Architecture Reference:** SyncButton component, POST /api/sync/budgets
**Design Reference:** Button design tokens, Toast notifications
