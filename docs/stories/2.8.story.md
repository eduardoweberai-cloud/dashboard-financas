# Story 2.8: Botão Resincronizar Metas (Fase 0 - UI)

**Status:** Ready for Review
**Story ID:** 2.8
**Objective:** Permitir re-sincronização manual de metas projetadas com UI feedback

---

## 📋 Descrição

Criar botão "↻ Resincronizar Metas" no canto superior direito do dashboard (próximo ao seletor de período). Clique dispara API `/api/sync/budgets` (implementado em Story 1.2). Exibe loading spinner enquanto sincroniza. Toast feedback ao completar: "Metas atualizadas com sucesso" (sucesso) ou "Erro ao sincronizar" (erro). KPIs e gráficos atualizam automaticamente após sucesso.

**PRD Reference:** Seção "Sincronização Inicial de Metas" (p. 241-249), UI (p. 247)
**Architecture Reference:** SyncButton component, POST /api/sync/budgets
**Design Reference:** Button design tokens, Toast notifications

### Implementation Summary

Implementado sistema completo de sincronização manual de metas:

1. **lib/api.ts** - Função helper para chamar `/api/sync/budgets` com suporte a AbortSignal
2. **hooks/useSyncBudgets.ts** - Custom hook com timeout de 30s e gerenciamento de estado loading/error
3. **components/ui/toast.tsx** - Sistema de toast notifications (success/error/info) com animações
4. **components/dashboard/SyncButton.tsx** - Componente principal com:
   - Loading state com spinner (Loader2 icon)
   - Button desabilitado durante sincronização
   - Toast feedback em sucesso/erro
   - Callbacks para refetch de dados
   - ARIA labels e tooltips para acessibilidade
5. **components/dashboard/DashboardHeader.tsx** - Integração do SyncButton no header
6. **app/layout.tsx** - Adição do ToastContainer como provider global
7. **tests/sync-button.test.ts** - Testes básicos e checklist manual para QA
